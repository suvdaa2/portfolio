PROJECT 01

Suika Game

A browser-based fruit merging game created to practice JavaScript, physics, and interactive game development.

Type Game Development
Technologies HTML · CSS · JavaScript · Matter.js
Focus Physics & Interaction

About the project

This project is a Suika Game-inspired fruit merging game. Players drop fruits into a container, and matching fruits merge into larger fruits.

I used Matter.js to create the physics, collisions, gravity, and fruit interactions, while JavaScript controls the game logic and scoring system.
